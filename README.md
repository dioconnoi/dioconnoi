## Featured projects

**[retail-profitability-risk](https://github.com/dioconnoi/retail-profitability-risk)** — End-to-end retail analytics case study (Olist marketplace, ~96k orders): SQLite data model with 22 reconciliation tests, demand forecasting with a rolling-origin backtest, risk metrics (HHI, drawdown, stress scenarios), three leakage-tested ML models (late delivery, review risk, seller failure), and a Power BI package. Shows the full analyst stack: SQL, Python, BI, and risk modelling, with every result checked against an independent recomputation.
